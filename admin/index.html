Admin Undangan

Masuk dengan token GitHub

Token dipakai untuk menyimpan undangan langsung ke repo. Token hanya disimpan di browser ini.

Cara membuat token (sekali saja):
  1. Buka github.com/settings/personal-access-tokens/new
  2. Token name: admin-undangan. Expiration: sesuai kebutuhan.
  3. Repository access: Only select repositories, lalu pilih Undangan-C-S.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Klik Generate token, salin, lalu tempel di bawah.

Kirim undangan

Ketik nama tamu dan nomor WA. Pesan dan link khusus dibuat otomatis, dan nama tamu tampil di sampul undangan. Tekan Kirim via WhatsApp, lalu tekan kirim di WhatsApp.

Pratinjau pesan:

Daftar tamu

Daftar tamu dan nomor WA hanya disimpan di browser ini, tidak diunggah ke GitHub (repo bersifat publik). Gunakan Unduh CSV untuk cadangan atau untuk dibuka di HP lain.

Tambah banyak sekaligus

Satu tamu per baris: nama, nomor. Contoh: Bapak Joko, 081234567890

Kata-kata undangan

Bisa diubah sesuka hati. Kata dalam kurung kurawal akan diganti otomatis:

{nama}{link}{mempelai}{tanggal}{tempat}

Undangan baru

Tema

Mempelai

Acara

Hitung mundur memakai tanggal dan jam mulai acara pertama. Bila akad dan resepsi di tempat yang sama, centang "Tempatnya sama dengan acara pertama" sehingga undangan cukup menampilkan satu peta. Klik peta untuk menaruh titik lokasi; tamu bisa mengetuk peta untuk membuka Google Maps.

Video khusus (opsional)

Video besar di atas galeri, misalnya prewedding. Bila tidak diisi, bagian ini tidak tampil di undangan.

Galeri foto & video

Bisa campur foto (jpg, png, webp) dan video (mp4). Video sebaiknya di bawah 25 MB supaya cepat dibuka. Urutan bisa digeser. Bila kosong, galeri tidak tampil di undangan.
